Nuevo usuario

El usuario es por cargo, no por persona: por ejemplo direccion, recepcion-afterschool o profesor-afterschool-1. Se genera una contraseña temporal que se muestra una sola vez; la persona la cambia al entrar.

Contraseña temporal

Cópiala ahora y entrégasela a la persona por un canal privado. No se volverá a mostrar: si se pierde, reinicia la contraseña otra vez. Al entrar se le pedirá elegir una propia.

Nombre de

Sale en el saludo y arriba a la derecha. El usuario para entrar no cambia. Vacío = se muestra el usuario.
